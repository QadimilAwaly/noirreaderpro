Fitur & Arsitektur

Dirancang untuk Pengalaman Membaca Fokus

Setiap komponen dioptimalkan untuk performa tinggi, efisiensi konsumsi daya, dan antarmuka yang ramah di mata.

Multi-Format Support

Parser EPUB Mandiri Tanpa Dependensi Berat

Noir Reader Pro menyertakan parser EPUB bawaan menggunakan pustaka standar Python (zipfile + xml.etree + html.parser). Tidak membutuhkan alat pihak ketiga seperti Calibre atau Pandoc untuk memecah dan membaca berkas EPUB Anda.

  • ✓
    Pengurutan alami (natural sorting) otomatis pada seluruh berkas bab.
  • ✓
    Folder novel dapat menggabungkan format .txt, .md, dan .epub secara bersamaan.
  • ✓
    Dukungan pemindaian folder langsung (legacy mode) maupun katalog berbasis JSON (indexed mode).
# Arsitektur backend modular Noir Reader Pro
core/     Resolusi jalur aman (safe_join) & penyimpanan atomik
models/   Model data novel, bookmark, & progress (Pydantic)
services/ Katalog pustaka, pembaca isi, & parser EPUB bawaan
api/      FastAPI routers (library, chapters, progress, settings)
frontend/ HTML5 + CSS Soft Noir + Modular Vanilla JS
Dual-View Reading

Beralih Instan Antara Hasil Terjemahan & Teks Asli

Saat membaca file markdown terjemahan (Chapter_NN.md) atau katalog hasil translator, Noir Reader Pro secara otomatis mendeteksi bagian ## Hasil Terjemahan dan ## Teks Asli, memungkinkan Anda beralih tampilan dengan satu klik tombol.

  • ✓
    Membaca teks asli langsung tanpa perlu membuka file sumber secara terpisah.
  • ✓
    Format tebal (**tebal**) dan miring (*miring*) diproses otomatis menjadi paragraf HTML rapi.
  • ✓
    Pengaturan font, jarak baris, indentasi paragraf, dan margin secara real-time.

Multi-Root & State

Multi-Folder Library & Progres Tersimpan In-Folder

Kelola beberapa direktori novel sekaligus dengan mendefinisikan library_roots di config.json. Status bacaan dan penanda halaman disimpan langsung di dalam folder novel terkait, menjadikannya portabel dan mudah disinkronkan.

  • ✓
    Multi-Folder Library: Gabungkan koleksi dari internal storage, kartu SD, maupun folder download.
  • ✓
    In-Folder Progress: Berkas .<novel_name>_progress.json disimpan di folder novel, ikut tersinkron via Resilio Sync / Syncthing.
  • ✓
    Resume Otomatis: Otomatis membuka novel dan bab terakhir yang sedang dibaca saat aplikasi dibuka.
// Struktur berkas in-folder progress
/sdcard/Download/Novel_Library/Lord_of_the_Mysteries/
├── Chapter_01.md
├── Chapter_02.md
├── library_index.json
└── .lord_of_the_mysteries_progress.json  <-- Otomatis tersimpan

Persyaratan & Instalasi

Prasyarat: Python 3.11+. Ikuti langkah di bawah ini untuk menjalankan server lokal Noir Reader Pro.

# 1. Update paket dan instalasi Python & Git
$pkg update && pkg install python git
# 2. Kloning repositori Noir Reader Pro
$git clone https://github.com/QadimilAwaly/noirreaderpro.git
$cd noirreaderpro
# 3. Instalasi dependensi
$pip install -r requirements.txt
# 4. Berikan izin akses penyimpanan bersama Android
$termux-setup-storage
# 5. Jalankan server lokal di port 3030
$python main.py
# 1. Kloning repositori resmi
$git clone https://github.com/QadimilAwaly/noirreaderpro.git
$cd noirreaderpro
# 2. Instalasi dependensi Python
$pip install -r requirements.txt
# 3. Jalankan server aplikasi
$python main.py
# Buka http://127.0.0.1:3030 di peramban web Anda

Konfigurasi Cepat (config.json)

Edit file config.json di root proyek untuk menetapkan folder koleksi novel Anda:

{
  "library_roots": [
    "/sdcard/Download/Novel_Library"
  ]
}

* Field global_storage_path juga dikenali secara otomatis.

Pengelolaan Daya & Proses (Termux)

Aplikasi berjalan sebagai server lokal uvicorn di port 3030. Untuk menghemat daya baterai perangkat:

  • •
    Hentikan foreground: Tekan Ctrl + C di terminal.
  • •
    Hentikan proses latar belakang: Jalankan pkill -f "python main.py".
# Hentikan proses Noir Reader Pro di latar belakang
pkill -f "python main.py"
